# Unit Conversion Tables — Open Dataset

Open, machine-readable **unit conversion tables** covering 11 categories and 70+ units — the data behind [ClearConvertor](https://clearconvertor.com), a free online unit converter.

## Categories
length, mass, area, volume, speed, energy, pressure, power, data storage, temperature, angle

## Format

- `unit-conversion-tables.json` — one file, all categories
- Model: each unit has a **factor to the category base unit** (e.g. `1 inch = 0.0254 meter`)
- Temperature uses formulas (offset scales)

## Use
Free to use with attribution and a link to [clearconvertor.com](https://clearconvertor.com). Useful for apps, spreadsheets, homework tools, embedded systems and research.
